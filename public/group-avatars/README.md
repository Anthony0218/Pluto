# Group avatar art

Generated with the built-in image generation tool. Each illustration was
generated separately and resized to 256 × 256 pixels for the app. Final assets:

- `chess-king.png`
- `chess-knight.png`
- `cards.png`
- `dragon.png`
- `forest.png`

Shared prompt: “Square community avatar for a multiplayer strategy game web
app. Polished illustrated enamel and carved metal, premium game collectible,
bold readable silhouette. One centered subject filling most of the square;
simple circular medallion behind it. Soft dramatic rim light. Deep indigo and
antique gold with subtle violet accents. No text, letters, logo, watermark,
copyrighted characters, or border. Readable at 48 pixels.”

Individual subjects: elegant chess king figurine; elegant chess knight
figurine; crossed playing cards with a crown motif and generic suits; dragon
head; forest tree.
